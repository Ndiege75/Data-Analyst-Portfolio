# Data Analyst Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Run locally
1. Download and extract the project folder.
2. Open `index.html` in a browser.

For live-reload development, open the folder in VS Code and use the Live Server extension.

## Before publishing
- Verify and edit the About section.
- Add accurate job titles, organisations and dates to Experience.
- Replace placeholder email and LinkedIn links.
- Create a separate GitHub repository for each project and update project links.
- Only publish anonymised or public datasets. Do not upload employer, customer or personal data.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `data-analyst-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for the published site link to appear in the Pages section.
